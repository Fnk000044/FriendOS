# 07 - 设计系统

> 最后更新日期：2026-07-15  
> 维护者：FriendOS Team

## 概述

FriendOS 采用毛玻璃（glassmorphism）+ pastel 渐变的设计语言，主色 teal，中文优化字体 HarmonyOS Sans SC。所有设计 token 集中在 `pc/src/index.css` 的 CSS 变量，Tailwind 在 `pc/tailwind.config.js` 映射。

## 字体

### 字体栈
- 主字体：`HarmonyOS Sans SC`（自托管 woff2）
- 备用：`Microsoft YaHei` → `system-ui` → `sans-serif`
- 等宽：`JetBrains Mono` → `Cascadia Code` → `Consolas`（`--font-mono` token，AI 代码块使用）
- 权重：400 Regular / 500 Medium / 700 Bold
- `@font-face` 声明：`pc/src/index.css:5-29`，`font-display: swap`
- 字体文件：`pc/public/fonts/HarmonyOS_Sans_SC_{Regular,Medium,Bold}.woff2`

## 动效

### 过渡 token（`:110-112`）
- `--transition-fast`: 150ms cubic-bezier(.4,0,.2,1)
- `--transition-smooth`: 300ms
- `--transition-spring`: 500ms cubic-bezier(.34,1.56,.64,1)（overshoot）

### Keyframes（~25 个，`pc/src/index.css`）
| Keyframe | 用途 |
|----------|------|
| fadeIn/fadeOut/fadeInUp/fadeInScale/scaleIn | 淡入 |
| slideInRight/slideInLeft/slideUp/slideInFromLeft | 滑入 |
| ellipsis/blink | 省略/光标 |
| pulseBorder/pulseGlow/statusPulse | 脉冲边框/光晕/状态 |
| shake | 抖动（错误） |
| pageEnter/pageTransitionEnter | 页面切换 |
| breatheIn/breatheOut/breatheGlow | 呼吸引导 |
| float/cardFloat | 浮动 |
| fadeSlideUp/staggerFadeUp/popIn | 交错淡入 |
| shimmer | 骨架闪烁 |
| modalScaleIn/modalScaleOut/windowAppear | 弹窗/窗口 |

### 工具类
`.fade-in` `.fade-in-up` `.fade-in-scale` `.slide-in-right` `.slide-in-left` `.slide-up` `.animate-shake` `.page-enter` `.page-transition-enter` `.window-appear` `.card-float` `.scan-line` `.breathe-glow` `.spectrum-slide` `.pop-in` `.count-up` `.status-pulse` `.stagger-in`(6×60ms) `.stagger-animate`(8×50ms) `.animate-shimmer`

### Tailwind 扩展动画（`tailwind.config.js:44`）
`float`(20s) / `float-slow`(25s) / `float-slower`(30s)

### 无障碍
`@media (prefers-reduced-motion: reduce)` 将所有动画/过渡时长置 0.01ms。
> ⚠️ `AnimatedNumber` 的 rAF 循环不受此影响（计划修复：检测后跳终值）。

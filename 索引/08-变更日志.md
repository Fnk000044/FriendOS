## 2026-07-16 Batch 10：在线模型接入（已移除）

> 本次尝试接入超星 CxRobotSdkJs 在线模型，经多轮验证（无头 SDK、webview 嵌入 prime/embedChat、iframe + 本地 host HTML）均不可行——超星 SDK 是嵌入式聊天浮窗，不提供程序化收发消息接口，且 prime/embedChat 页面对非授权来源拒绝访问。已全部移除，恢复纯离线架构。

### 已移除的改动（全部回退）
- [pc/electron/online/] 目录删除（robot-host.html / robot-preload.cjs）
- [pc/electron/services/OnlineModelService.cjs] 删除
- [pc/src/services/ai/providers/OnlineModelProvider.ts] 删除
- [pc/src/components/assistant/OnlineChatPanel.tsx] 删除
- [pc/electron/main.cjs] 移除 online-model-* IPC、webviewTag、CSP 超星域名放行、before-quit 在线 dispose
- [pc/electron/preload.cjs] 移除 onlineModel* API
- [pc/src/types/electron.d.ts] 移除 onlineModel* 类型
- [pc/src/services/ai/types.ts] AIConfig.provider 改回 'local'，删除 OnlineConfig
- [pc/src/services/ai/AIService.ts] 移除 online 分支，恢复纯 local provider 逻辑
- [pc/src/stores/aiStore.ts] defaultConfig.provider 改回 'local'，移除 setProvider，恢复 partialize/merge 强制 tone='counselor'
- [pc/src/hooks/useAI.ts] 移除在线相关错误处理和回退逻辑
- [pc/src/components/ai/AISettingsModal.tsx] 移除在线/离线切换 UI，恢复纯离线设置
- [pc/src/components/assistant/ChatPanel.tsx] 移除 OnlineChatPanel import 和 provider 分支

### 原因
- 超星 SDK `init` 返回的实例用 `invoke('send')` 发消息后，机器人不会回 `message` 事件（SDK 是聊天浮窗，靠用户在 UI 里手动聊天）
- prime / embedChat 页面直接嵌入会"无权限访问"（来源校验失败）
- 本地 host HTML + SDK init 方案能加载形象，但上下文注入依赖超星聊天窗口的 DOM 结构，不稳定
- 结论：超星方案不适合作为可程序化调用的在线模型，已全部移除

### 验证
- `npx tsc --noEmit` 通过（仅预存 test/setup.ts vi 报错）
- 应用恢复为纯离线 Qwen3.5-0.8B 架构，功能不受影响

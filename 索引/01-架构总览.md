## 数据流

### AI 对话流
```
用户输入 → ChatPanel.handleSubmit
  → (异步) SentimentService.cjs 三层危机检测
  → useAI.sendMessageStream
    → AIService.sendMessageStream
      → ContextService.gatherContext（DB 查询，5min TTL 缓存）
      → buildSystemPrompt（prompts.ts，含 tone/context/history）
      → LocalModelProvider.chatStream
        → IPC: local-model-complete-stream
          → LocalModelService.cjs.completeStream（node-llama-cpp）
          → 逐 chunk 通过 onChunk 回调
        → 渲染：useAI 缓冲 16ms 刷新 → ChatMessage 流式渲染
```

### 情感/风险分析流
```
日记保存 → DiaryEditor
  → IPC: emotion:analyzeDiary
    → EmotionAnalysisEngine.analyzeDiary
      → SentimentService.analyzeEnhanced（ONNX + 关键词 + Qwen）
      → extractEmotions / extractPANAS
    → 写入 db.emotionRecords
  → 若 riskLevel === 'high' → crisisStore.show（危机弹窗）
```

## 关键设计决策

1. **完全本地化**：所有 AI 推理（Qwen + ONNX）在本地完成，无云端调用，保护隐私。
2. **三层危机检测**：关键词预筛 → ONNX 概率 → Qwen 语义确认，逐层升级避免漏报。
3. **毛玻璃设计语言**：`glass-card` + pastel 渐变背景，HarmonyOS Sans SC 字体。
4. **无 JS 动画库**：纯 CSS keyframes（~25 个）+ `requestAnimationFrame`（AnimatedNumber）。
5. **Dexie 版本化 schema**：每次表结构变更新增 `version(N).stores()`，向前兼容。
6. **干预闭环（2026-08 新增）**：识别（三层检测/五信号评分）→ 干预（CBT/呼吸/正念/科普库）→ 转介与自助（危机弹窗 + 热线 + SPI 安全计划）；证据链保证可解释。
7. **报告可携带（2026-08 新增）**：心理报告经渲染层 HTML 构建 → 主进程隐藏窗口 `printToPDF` → A4 PDF（用户内容全量转义，无脚本执行）。
8. **敏感字段加密**：日记/反馈/自进化参数/安全计划六字段均走 `crypto.ts` AES-GCM 字段级加密。

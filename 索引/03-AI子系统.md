# 03 - AI 子系统

> 最后更新日期：2026-07-16  
> 维护者：FriendOS Team

## 概述

FriendOS 的 AI 子系统完全本地化运行，包含两大模型：

1. **Qwen3.5-0.8B-IQ4_NL**（GGUF，~507MB）—— 对话/报告生成/危机语义确认
2. **BERT 3-class 情感分类**（ONNX，~103MB）—— 文本情感极性分类

所有推理在 Electron 主进程完成，通过 IPC 暴露给渲染进程。

## 模型管理

### ModelRegistry（`pc/electron/services/ModelRegistry.cjs:18`）
- 注册 `qwen3.5:0.8b`，路径解析支持打包（`resources/models/`）和开发（`pc/models/`）。
- `getModelPath(id)` 返回绝对路径。

### LocalModelService（`pc/electron/services/LocalModelService.cjs`）
- 基于 `node-llama-cpp`（ESM 动态导入）。
- `ensureModel()`：缓存 model + context（contextSize 2048）。
- `createSession()`：每会话复用共享 sequence，`sequence.clearHistory()` 防 KV 残留。
- `complete()`：非流式，temp=0.7/top_p=0.8/top_k=20/maxTokens=512，追加 `/no_think`。
- `completeStream()`：流式，`ThinkFilter` 状态机跨 chunk 剥离 `</think>` 块。空响应重试一次 `complete()`。
- `dispose()`：清 sequence/context/model。

### IPC 接口（`pc/electron/main.cjs`）
| IPC Channel | 行 | 说明 |
|-------------|-----|------|
| `local-model-init` | :405 | 初始化 Qwen |
| `local-model-complete` | :428 | 非流式推理 |
| `local-model-complete-stream` | :448 | 流式推理（event-based，120s 超时） |
| `local-model-dispose` | :529 | 释放模型 |
| `local-model-list` | :380 | 模型列表 |

## 渲染层 AI 服务

### AIService（`pc/src/services/ai/AIService.ts`）
- `initialize(config)`：按 `config.provider` 分支选择 OnlineModelProvider / LocalModelProvider，**读取 `config.tone`（不再强制 counselor）**，让 AISettingsModal 语气选择生效。
- `sendMessageStream`：
  1. `sanitizeUserInput`（NFKC + 零宽字符移除 + 注入模式过滤 + 5000 字截断）
  2. `contextService.gatherContext()`（DB 查询，5min TTL）
  3. `buildSystemPrompt(config.tone, context, history)` —— 在线/离线均注入完整系统提示
  4. 组装 messages：system + history（过滤空） + user
  5. `provider.chatStream(messages, context, onChunk)`

### ContextService（`pc/src/services/ai/ContextService.ts`）
收集用户实时状态注入 system prompt：
- 今日任务（待办/完成/逾期）
- 最近 3 篇日记（含 mood emoji）
- 今日习惯清单
- 近期 5 条记忆
- 对话摘要历史
- 学期阶段检测（StudentAdaptationService）
- 含蓄表达检测（detectImplicitExpression）

### prompts.ts（`pc/src/services/ai/prompts.ts`）
- `getTonePrefix(tone)`：5 种语气模板（professional/friendly/concise/encouraging/counselor）
- counselor 模式含 CBT 框架 + 中国文化敏感性（病耻感/面子/孝道）
- `CRISIS_PROTOCOL`：危机处理协议（表达关心→询问自伤→提供热线 400-161-9995）
- `DISCLAIMER`：AI 助手免责声明
- `buildSystemPrompt`：组装 tonePrefix + disclaimer + 用户状态 + 对话记忆 + 回复要求

### ReportAIService（`pc/src/services/ai/ReportAIService.ts`）
- `generateAIReport(start, end)`：优先 Qwen 生成 JSON 报告，失败回退 `generateWithRules`。
- `generateAIReportStream(start, end, onSummaryChunk)`：流式输出 summary（逐字），insights/suggestions 用 JSON 解析。Qwen 失败回退规则。
- system prompt 含结构化输出要求 + 2 个 few-shot 示例，`maxTokens` 1024，`temperature` 0.6。
- 趋势计算：7 日移动平均，阈值 ±0.5。

### ConversationMemory（`pc/src/services/ai/ConversationMemory.ts`）
- `saveConversationSummary(msgs)`：对话后保存摘要候选。
- `getRecentSummaries` / `formatSummariesForContext`：提供 AI 上下文。

## 流式输出链路

```
用户发送 → useAI.sendMessageStream
  → AIService.sendMessageStream
    → LocalModelProvider.chatStream
      → IPC: local-model-complete-stream
        → LocalModelService.completeStream
          → LlamaChatSession.prompt（streaming callback）
          → ThinkFilter 剥离 <think> 块
          → 每个 chunk → IPC event → renderer onChunk
  → useAI 缓冲 16ms 刷新（STREAM_FLUSH_INTERVAL）
  → useAIStore 更新 assistant message content
  → ChatMessage 流式渲染（纯文本 + blink 光标）
  → 完成后转 ReactMarkdown 渲染
```

## 已知限制

1. **Qwen3.5-0.8B 能力边界**：0.8B 参数对结构化 JSON 输出不稳定，需大量兜底（ThinkFilter/stripThinking/空响应重试）。
2. **`/no_think` 双重保险**：system 和 user prompt 都追加，说明该指令在当前构建不够可靠。
3. **历史窗口**：已扩展到 `slice(-8)`（4 轮），上下文 2048 够用。
4. **tone**：已改为读取用户选择，不再强制 counselor。
5. **`WeeklyReportService.ts` 已删除**：复盘统一走 `ReportAIService.generateAIReportStream`，规则仅作兜底。

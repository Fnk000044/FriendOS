# FriendOS 项目索引

> 最后更新日期：2026-07-15  
> 维护者：FriendOS Team

本目录是 FriendOS 项目的说明文档总索引，旨在帮助后续开发者快速了解项目架构与每次改动内容。

## 全局工作要求

**每次代码修改完成后，必须同步更新本目录下的索引文件：**

1. `08-变更日志.md` — 追加一条改动记录（日期/改动/原因/验证）
2. 对应专题文档（`01` ~ `07`）— 若改动触及该文档覆盖范围，同步更新相关章节
3. `09-本次升级记录.md` — 本次升级期间，每次批次完成追加一条记录
4. `README.md` — 若新增/删除文档文件，更新本导航
5. 代码引用统一用 `file_path:line_number` 格式（可点击定位）

## 页面职责详解

### DashboardPage（`pc/src/pages/DashboardPage.tsx`）
- 顶部问候+日期（useClock 实时更新）+ QuickStats（4 列统计）
- 主内容区**严格两列网格**（`md:grid-cols-2 items-stretch`），DailyQuote 跨两列置底
- Mount 时：`initService()` 预热 AI + `generateHealthProfile()` 生成基线
- 实时计算 dailyRecord（任务/习惯/日志计数变化时）

### RiskDashboardPage（`pc/src/pages/RiskDashboardPage.tsx`）
- 心理守护概览（标题 `risk.dashboard_title`）
- 风险评分卡（强化：大色块背景 + 5 格等级条 + 高风险行动指引）+ 个人基线对比 + 健康维度雷达（`<RiskRadar>` 组件）+ 风险趋势折线 + 信号源分析（4 态标签）+ 风险因素列表（严重因素红底）
- 4 个 LiveQuery（emotionRecords/behaviorRecords/assessments/diaries）+ riskCalculate IPC
- 15s 超时保护 → 非阻塞提示条 + 部分渲染（非整页 EmptyState）
- ⚠️ 前端仍重复实现 5 个 `calculateConsecutive*` 函数（计划改调后端 IPC）

### TasksPage（`pc/src/pages/TasksPage.tsx`）
- 顶部视图切换 Tab：列表 / 看板 / 日历
- 列表视图：4 个 TaskSection（today pending / overdue / completed / rollover）+ TaskStats
- 看板视图：3 列拖拽（TaskBoard）
- 日历视图：月历 + 优先级色点（TaskCalendar）
- TaskDetailModal 新建/编辑（含截止时间/提醒/子任务）

### ReportsPage（`pc/src/pages/ReportsPage.tsx`）
- 日期范围选择 → `generateReport`（规则）+ `generateAIReport`（Qwen）并行
- StatCards + AI 报告 + HealthRadar + EmotionTrend + WeeklyReportCard + 3 图表
- 已删除强制 300ms 最小延迟

### AssistantPage（`pc/src/pages/AssistantPage.tsx`）
- ChatPanel 全屏包装
- 进入时折叠侧边栏，离开恢复

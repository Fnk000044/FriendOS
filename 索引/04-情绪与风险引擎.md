# 04 - 情绪与风险引擎

> 最后更新日期：2026-07-15  
> 维护者：FriendOS Team

## 概述

四个后端服务协作完成情绪分析与风险评估，均在 `pc/electron/services/`。

## SentimentService（`SentimentService.cjs`）

文本情感分析入口，三层危机检测（详见 [03-AI子系统](./03-AI子系统.md)）。

### 关键函数
| 函数 | 行 | 说明 |
|------|-----|------|
| `analyze(text)` | :300 | 基础分析（关键词 only），危机=medium |
| `analyzeWithONNX(text)` | :347 | ONNX 推理，返回 {neg,neu,pos,confidence,method} |
| `analyzeEnhanced(text)` | :227 | 完整三层：关键词+ONNX+Qwen |
| `qwenAnalyze(text)` | :161 | Qwen 语义确认，temp=0.3 |
| `tryLoadOnnxModel()` | :427 | 懒加载 ONNX session |
| `tokenizeForBERT(text)` | :479 | 手写 BERT WordPiece 分词 |

### 置信度与方法标记（分层策略）
- `maxProb >= 0.85` → method='onnx'（高置信，直接采信）
- `0.55 ≤ maxProb < 0.85` → method='onnx-midconf'（中置信，与关键词加权）
- `maxProb < 0.55` → method='onnx-lowconf'（低置信，触发 Qwen）

### 关键词层负例平滑
- 分母 `max(total,4)`（原 8，避免短文本被过度稀释）
- 极短文本（<6 字）由 ONNX 主导

### 危机排除词
- `想死了`/`想去死` 已从 `CRISIS_EXCLUSIONS` 移除，关键词层命中即 medium，交 ONNX+Qwen 确认

## EmotionAnalysisEngine（`EmotionAnalysisEngine.cjs`）

### 两套情绪模型
1. **PANAS**（Watson 1988，中文版）— `PANAS_KEYWORDS`（:20-163）
   - 10 正向情感维度（interested/excited/strong/...）
   - 10 负向情感维度（distressed/upset/guilty/...）
   - `extractPANAS`（:349）：加权求和
2. **Legacy 六维 Ekman**（:167-304）
   - joy/sadness/anger/fear/surprise/disgust
   - `extractEmotions`（:317）：归一化

### 关键函数
| 函数 | 行 | 说明 |
|------|-----|------|
| `analyzeDiary(content, mood?)` | :448 | 日记全分析（ONNX+情绪+PANAS+社交+睡眠） |
| `analyzeConversation(messages)` | :494 | 对话分析（仅 user 消息） |
| `calculateHealthIndex(data)` | :519 | 加权 0-100：sentiment .20 + mood .20 + task .15 + habit .15 + social .15 + sleep .15 |
| `calculateRiskLevel(data)` | :564 | 危机词→critical；情绪风险加分；连续低心情+30；波动+15 |
| `generateInsights(data)` | :644 | 文本规则洞察 |
| `generateSuggestions(data)` | :681 | 文本规则建议 |

### 风险等级阈值（`calculateRiskLevel`）
- `>= 60` → critical
- `>= 40` → high
- `>= 25` → medium
- `>= 10` → medium_low
- `< 10` → low

## RiskScoringEngine（`RiskScoringEngine.cjs`）

多信号加权综合风险指数（0-100）。

### 权重（`:19-25`）
| 信号 | 权重 |
|------|------|
| emotion 情绪 | 0.30 |
| behavior 行为 | 0.25 |
| assessment 评估 | 0.25 |
| chat 聊天 | 0.10 |
| diary 日记 | 0.10 |

### 风险等级（`:29-35`）
| 等级 | 分数范围 | 颜色 |
|------|----------|------|
| low | 0-25 | 绿 |
| medium_low | 26-50 | 琥珀 |
| medium | 51-75 | 橙 |
| high | 76-90 | 红 |
| critical | 91-100 | 深红 |

### 信号评分函数
| 函数 | 行 | 说明 |
|------|-----|------|
| `calculateEmotionScore` | :44 | avg sentiment → (1-avg)*50；高风险记录+30；波动>0.4 +15 |
| `calculateBehaviorScore` | :90 | 连续无日记阶梯(2/3/7/14天)；连续低心情；任务完成率下降+15；习惯中断+15；深夜>0.3 +10 |
| `calculateAssessmentScore` | :153 | PHQ-9(5/10/15/20→5/15/25/35)；GAD-7；PSS-10 |
| `calculateChatScore` | :219 | 危机词+40；3+负面词+20；1+ +10 |
| `calculateDiaryScore` | :263 | mood 映射 80/60/40/20/0 * 0.5；危机词+40；3+负面+15 |
| `calculateRiskScore(data)` | :324 | 加权求和→取整→选等级→排序因素 |
| `calculateRiskTrend(series)` | :392 | 前后两半均值，±5 阈值 |

## BehaviorAnalyzer（`BehaviorAnalyzer.cjs`）

个人基线 + 异常检测（StudentLife-inspired）。

### 关键设计
- `MIN_BASELINE_DAYS = 7`：不足 7 天数据时用硬编码阈值。
- `calculatePersonalBaseline`（:24）：返回 null 直到 7 天。
- `analyzeDailyBehavior`（:217）：用基线 ± std*1.5 检测异常。
- `analyzeBehaviorTrends`（:344）：连续无日记/低心情/任务完成率下降/习惯中断/深夜比。

### 打字行为分析（:96）
- `analyzeTypingBehavior`：打字速度 <20 字/分=medium 异常，<30=low
- `calculateTypingBaseline`（:169）：需 ≥3 次会话
- 删除率 >0.25=medium；停顿率 >8/min=medium

## crisisKeywords（`crisisKeywords.cjs`）

统一关键词表，避免之前三文件重复。

| 导出 | 说明 |
|------|------|
| `CRISIS_KEYWORDS` | 25 个危机词（想死/自杀/跳楼/生无可恋...） |
| `NEGATION_WORDS` | 9 个否定词（不会/不想/勿...） |
| `CRISIS_EXCLUSIONS` | 17 个误报排除（九死一生/笑死/累死了/想死了...） |
| `NEGATIVE_KEYWORDS` | 12 个负面词（用于风险评分） |

> ⚠️ `想死了`/`想去死` 已从 `CRISIS_EXCLUSIONS` 移除，关键词层命中即 medium，交 ONNX+Qwen 确认是否升级 high。

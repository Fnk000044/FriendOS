# FriendOS Competition Enhancement Plan

## Current Status
- **Project**: AI Mental Health Companion & Early Risk Identification Assistant
- **Tech Stack**: Electron + React + TypeScript, Local AI (Qwen3 0.6B), BERT sentiment analysis
- **Completion**: ~93% (v0.0.4)
- **Existing Features**: Tasks, Habits, Diary, Memories, AI Assistant, Emotion Tracking, Assessments (PHQ-9, GAD-7), Therapy Exercises, Crisis Intervention, Reports, Data Sync

## Key Files for Enhancement
1. `pc/src/services/emotion/RiskAssessment.ts` - Core risk assessment logic
2. `pc/src/services/emotion/HealthProfileService.ts` - 6-dimension health profiling
3. `pc/src/services/ai/ContextService.ts` - AI context gathering
4. `pc/src/services/ai/AIService.ts` - AI conversation management
5. `pc/src/services/emotion/InterventionRecommendationService.ts` - Therapy recommendations

## Proposed Improvements (Ranked by Competition Impact)

### P0 - High Impact (Implement First)

#### 1. Temporal Risk Pattern Detection
**Description**: Add sliding-window change point detection to identify deteriorating trends 3-5 days earlier than current system.
**Implementation**:
- Create `pc/src/services/emotion/TemporalRiskDetector.ts`
- Use CUSUM algorithm on 14-day rolling windows for each health dimension
- Detect simultaneous multi-dimensional declines (3+ dimensions declining = higher risk)
- Integrate into `RiskAssessment.ts:assessRisk()` as new factor with weight 20-35
**Impact**: Sophisticated early detection beyond keyword matching

#### 2. Health Profile Integration into AI Companion
**Description**: Give AI access to user's 6-dimension health profile and risk trends.
**Implementation**:
- Modify `ContextService.ts:fetchContext()` to include health profile data
- Add to AI context: "情绪: 45/100 | 压力: 72/100 | 趋势: 压力连续3天上升"
- Update `prompts.ts:buildSystemPrompt()` to reference health data naturally
**Impact**: AI conversations become genuinely personalized and data-driven

### P1 - Medium-High Impact

#### 3. Safety Planning & Crisis Follow-up
**Description**: Add Stanley & Brown Safety Planning Intervention after crisis events.
**Implementation**:
- Create `SafetyPlanService.ts` and `SafetyPlanWizard.tsx`
- 6-step safety planning workflow (warning signs, coping strategies, contacts, etc.)
- Add 24h, 72h, 7d follow-up nudges via `WellnessNudgeEngine`
**Impact**: Evidence-based crisis management, addresses post-crisis gap

#### 4. Adaptive Therapy Progression Engine
**Description**: Track therapy completion history, measure mood impact, dynamically adapt recommendations.
**Implementation**:
- Create `TherapyProgressionEngine.ts`
- Compute user's therapy profile (which modalities work best)
- Add progression logic (beginner → intermediate → advanced)
- Anti-stagnation: switch modality if no improvement after 3+ sessions
**Impact**: Personalized, evidence-based intervention recommendations

### P2 - Medium Impact

#### 5. Smart Wellness Nudge System
**Description**: Proactive notification engine monitoring behavioral patterns.
**Implementation**:
- Create `WellnessNudgeEngine.ts` with pattern detectors:
  - Disengagement detector (2+ days no activity)
  - Sleep disruption detector (late-night activity)
  - Positive reinforcement (mood improvement streaks)
  - Crisis recovery nudges (24h, 72h check-ins)
- Rate limiting: max 2 nudges/day, 4-hour gap
**Impact**: Proactive mental health support, not just reactive

#### 6. Longitudinal Analytics Dashboard
**Description**: Compute correlations between health dimensions, identify personal triggers.
**Implementation**:
- Create `LongitudinalAnalytics.ts`
- Compute Pearson correlations over 30/60/90 day windows
- Identify triggers: "Your stress spikes after late-night activity"
- Track milestones: "14 consecutive days of stress < 50"
- New component: `LongitudinalInsights.tsx`
**Impact**: Clinical-grade analytics, actionable insights

### P3 - Innovation Differentiators

#### 7. Digital Phenotyping Dashboard
**Description**: Combine passive behavioral signals into a "digital phenotyping" view.
**Implementation**:
- Create `DigitalPhenotypingService.ts`
- Extract signals from existing `BehaviorRecord` data:
  - Activity rhythm consistency
  - Engagement index (diary, tasks, habits)
  - Circadian alignment
  - Cognitive load proxy
- New component: `PhenotypingDashboard.tsx`
**Impact**: Novel, academically grounded, aligns with "unobtrusive detection"

#### 8. Context-Aware Mood Journaling Prompts
**Description**: Generate personalized journaling prompts based on health profile.
**Implementation**:
- Create `JournalPromptEngine.ts`
- Categories: gratitude, CBT restructuring, emotional granularity, behavioral activation
- Selection logic: stress > 70 → CBT prompts, social < 40 → connection prompts
- Integrate into `GuidedJournal.tsx` as "AI-guided journaling" mode
**Impact**: Transforms diary from passive recording to active therapeutic tool

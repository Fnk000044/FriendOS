# FriendOS 鸿蒙端三大功能实现计划

## 概述

实现三个优先功能：
1. **任务顺延 + 重复任务** - 自动顺延过期任务、支持重复任务创建
2. **深色模式 + 主题切换** - 完整的浅色/深色/跟随系统主题支持
3. **治疗练习** - 呼吸练习计时器、正念冥想播放、CBT思维记录表单

**建议实施顺序**: 功能2 → 功能1 → 功能3（先建主题基础设施，避免后续返工）

---

## 功能2: 深色模式 + 主题切换（优先实施）

### 目标
让 ThemeConfig 中定义的颜色真正生效，支持浅色/深色/跟随系统三种模式。

### 文件清单

| 操作 | 文件 | 说明 |
|------|------|------|
| 新建 | `stores/ThemeStore.ets` | 主题状态管理 |
| 修改 | `config/ThemeConfig.ets` | 添加 ThemeColors 辅助类 |
| 修改 | `entryability/EntryAbility.ets` | 启动时读取并应用主题 |
| 修改 | `pages/SettingsPage.ets` | 主题切换实际生效 |
| 修改 | `pages/Index.ets` | 全局使用主题颜色 |
| 修改 | 所有 components 和 pages | 替换硬编码颜色为 ThemeColors |

### 实现要点

1. **ThemeStore**: 使用 Preferences 持久化主题选择，通过 AppStorage 实现响应式更新
2. **ThemeColors**: 统一颜色访问接口，所有组件通过 `ThemeColors.background` 等获取颜色
3. **批量替换**: 将 `'#F8FAFC'` → `ThemeColors.background`，`'#FFFFFF'` → `ThemeColors.surface` 等

## 功能1: 任务顺延 + 重复任务

### 目标
- 启动时自动顺延过期任务（按优先级限制顺延次数）
- 支持创建重复任务（按天/周/月）

### 文件清单

| 操作 | 文件 | 说明 |
|------|------|------|
| 新建 | `utils/PreferencesUtil.ets` | 轻量级持久化工具 |
| 新建 | `utils/RolloverService.ets` | 任务顺延核心逻辑 |
| 修改 | `stores/TaskStore.ets` | 添加 createRecurringTasks 方法 |
| 修改 | `pages/TaskEditorPage.ets` | 添加重复任务配置 UI |
| 修改 | `pages/Index.ets` | 启动时调用顺延 + 显示 Banner |

### 实现要点

1. **顺延规则**: urgent/high 最多1次，medium 3次，low 无限制
2. **跨天判断**: 使用 Preferences 存储 lastVisit，与今天比较
3. **重复任务**: 循环创建多个任务实例，安全上限365次

## 功能3: 治疗练习（呼吸/正念/CBT）

### 目标
实现完整的治疗练习功能，包括呼吸练习计时器、正念冥想播放、CBT思维记录表单。

### 文件清单

| 操作 | 文件 | 说明 |
|------|------|------|
| 新建 | `stores/TherapyStore.ets` | 治疗记录存储 |
| 新建 | `components/therapy/BreathingExerciseComponent.ets` | 呼吸练习组件 |
| 新建 | `components/therapy/MindfulnessSessionComponent.ets` | 正念冥想组件 |
| 新建 | `components/therapy/ThoughtRecordComponent.ets` | CBT思维记录组件 |
| 修改 | `pages/TherapyPage.ets` | 替换为实际功能组件 |

### 实现要点

1. **呼吸练习**: 4种模式（4-7-8/方框/简单/共振），动画圆圈，计时器，情绪评分
2. **正念冥想**: 3种类型（身体扫描/觉察呼吸/慈悲冥想），安全筛查，步骤引导，进度环
3. **CBT思维记录**: 7步向导，15种认知扭曲标签，情绪强度评分，证据评估

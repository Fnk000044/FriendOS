# 2026-08-03 工作日志

## v3 打包：仅生成可运行 exe（portable 免安装版）

用户要求"只生成 exe 可运行文件，不用安装包"。产出：`pc/release-v3-portable/FriendOS 0.0.5.exe`（173.7MB，portable 单文件双击即运行）+ `win-unpacked/` 绿色版目录（216MB exe + asar 78.8MB + 模型 99.2MB）。

### 关键经验（下次打包直接照抄）
1. **必须显式带 `--config electron-builder.json`**：不带时 files 白名单不生效 → 全量打包（asar 4.95GB 且输出目录循环打进去）。正确命令：
   `npx electron-builder --win portable --config electron-builder.json --config.directories.output=release-<新目录> --config.win.signAndEditExecutable=false`
2. **必须 `signAndEditExecutable=false`**：winCodeSign 7z 在本地反复解压失败（Archives with Errors: 1），electron-builder 内置 rcedit 用不了；跳过即可，**portable 图标在 NSIS 编译 stub 时已用 installerIcon 嵌入，不需要 rcedit**
3. **禁止对 portable exe 再手动跑 rcedit 注入图标**：portable = NSIS stub + 7z 拼接体，rcedit 直接重写会把 exe 从 174MB 破坏成 57KB！win-unpacked 版可安全注入（已验证 216MB 完好，rcedit-x64.exe 在 `$LOCALAPPDATA/electron-builder/Cache/winCodeSign/<hash>/`）
4. 打包末尾"清理临时 7z 被 safe-delete 拦截"的报错**可忽略**——exe 已生成，只是沙箱拦了 electron-builder 内部的临时文件删除；事后手动删 7z 中间产物（用 python os.remove，rm 会被回收站机制拦）
5. 打包后启动验证注意：本自动化会话无交互桌面，GUI 启动后"退出码 0"是环境限制（v2 产物同样行为），不代表打包有问题；用户桌面双击正常

### 验证结果
- 图标验证：两个 exe 的 .rsrc 段均含 PNG 帧（Sparkles 视觉，portable 6 帧多尺寸 / win-unpacked 1 帧）
- asar 78.8MB 正常（对比：不带 --config 时 4.95GB 异常）
- 失败产物目录（release-portable/2/3/final，共 ~8GB）因 app.asar 被系统扫描占用未能删除，重启后可手动清理

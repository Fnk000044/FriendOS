# FriendOS 现状调研摘要（主理人已核实的事实，团队共享）

> 整理：主理人齐活林，2026-08-01。供架构师/工程师/QA 引用，避免重复调研。

## 一、AI 能力实测结论

### 1. ONNX 情感分类模型 —— ✅ 已跑通（实测）
- 位置：`pc/models/sentiment/sentiment.onnx`（~103MB，INT8 动态量化）+ `vocab.json`（21128 词）
- 4 分类：`{negative:0, neutral:1, positive:2, crisis:3}`
- 实测推理（onnxruntime-node）：
  - "我真的撑不下去了，想死" → crisis (0.993) ✅
  - "最近压力有点大，有点焦虑" → negative (0.975) ✅
  - "笑死我了这个梗太好笑了" → neutral (0.661) ✅
- 指标（同分布测试集 6050 条）：accuracy 97.57%、crisis recall 98.87%（见 `pc/models/sentiment/sentiment.eval.json`）
- 推理接口：输入 `input_ids`/`attention_mask`（int64，pad 128），输出 `logits`

### 2. 训练链路 —— ✅ 完整（Python 脚本，独立于应用）
- 目录：`pc/scripts/train_sentiment/`
- 流程：`build_dataset.py`（3 数据集解析+关键词弱标注）→ `augment.py`（增强）→ `merge_dataset.py`（合并）→ `train.py`/`train_full.py`（BERT 4分类）→ `export_onnx.py`（导出+量化）→ `eval_onnx.py`（评估）
- 训练数据：`data/train_final.jsonl`（24200 条，四分类均衡）、`data/test_final.jsonl`（6050 条）
- 数据来源分布：ds1_soulchat 59% / augmented 21% / public 6% / ds3_r1 9% / ds2_catch 5%
- 远程训练结果：`output/remote_results/`（run1-3 + ensemble.onnx + checkpoints）
- ⚠️ 小 bug：`export_onnx.py` 的 `test_inference` 函数 `label_names = ["negative", "neutral", "positive"]` 仍是 3 类（实际 4 类），需修正

### 3. 对话 AI —— ⚠️ 依赖云 API，离线只有模板
- 云链路：`pc/electron/services/ChatLLMService.cjs`（主进程 Node fetch 代理，通义千问 qwen-plus / DeepSeek deepseek-chat，SSE 流式）
- Key 管理：`ApiKeyStore.cjs`（DPAPI 加密，`chat_llm` / `chat_llm_provider`）
- 降级链：`ChatFallbackEngine.cjs`（模板引擎：时间感知开场 + 情绪分支共情/追问组合 + 危机固定回复 + 去重）
- IPC：`chat:send` / `chat:testConnection` / `chat:getProviderConfig` / `chat:fallback` / `chat:greeting`；事件 `chat:chunk`
- 前端编排：`src/services/ai/ChatService.ts`（写 user → sentimentAnalyze → crisis 则触发危机弹窗 → chat:send 流式 → 失败降级 chatFallback）
- 状态：`src/stores/chatStore.ts`（ChatProviderStatus: cloud/fallback/connecting/error）
- 页面：`src/pages/ChatPage.tsx` + `components/chat/{MessageBubble,TypingIndicator,QuickReplySuggestions}.tsx`
- 设置：`components/settings/ChatLLMSettings.tsx`
- ⚠️ **本地 Qwen GGUF 不存在**：文档宣称离线 Qwen3.5-0.8B，实际 `pc/models/` 只有 sentiment；local-model IPC 已从 main.cjs 移除

### 4. "AI 预测"实为规则+统计（无真 ML 预测）
- `RiskScoringEngine.cjs`：5 信号加权（情绪 0.30/行为 0.25/评估 0.25/聊天 0.10/日记 0.10）→ 0-100 → 5 级风险（low/medium_low/medium/high/critical）
- `src/services/emotion/EarlyWarningService.ts`：5 个 3 天窗口特征 + 线性回归斜率 + 异常分 + 预警等级（green/yellow/orange/red）
- `src/services/emotion/EmotionPredictionService.ts`：移动平均 + 斜率 + 波动率 → 趋势方向
- `BehaviorAnalyzer.cjs`：个人基线（≥7 天）+ 异常检测 + 打字行为分析
- 前端展示：`src/pages/RiskDashboardPage.tsx`（早期预警卡片 EarlyWarningCard、风险评分 RiskScoreCard、信号源 RiskSignalSources、趋势 RiskTrendChart/RiskTimelineChart、健康雷达 RiskRadar/HealthRadar）

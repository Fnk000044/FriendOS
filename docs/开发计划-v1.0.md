## 二、核心功能实现

### 2.1 Phase 1: 统一风险画像（最高优先级）

**目标**: 展示"早期风险识别"核心能力

#### 2.1.1 综合风险评分引擎
**新建**: `pc/electron/services/RiskScoringEngine.cjs`

```
信号源融合:
├── 情绪分析 (30%) ← emotionRecords
├── 行为异常 (25%) ← BehaviorAnalyzer
├── 评估量表 (25%) ← assessments (PHQ-9/GAD-7/PSS-10)
├── 聊天情感 (10%) ← conversationSummaries
└── 日记情绪 (10%) ← diaries.mood

风险等级: 0-25低 / 26-50中低 / 51-75中 / 76-90高 / 91-100危急
```

IPC handlers:
- `risk:calculate` - 计算当前风险评分
- `risk:getTrend` - 获取近7/30天趋势

#### 2.1.2 风险仪表盘页面
**新建**: `pc/src/pages/RiskDashboardPage.tsx` (路由: `/risk`)

组件:
- **综合风险评分卡片**: 大数字 + 颜色指示(绿/黄/橙/红) + 滚动动画
- **六维雷达图** (Recharts RadarChart): 情绪/行为/社交/睡眠/压力/自理
- **风险趋势折线图**: 近7天/30天切换
- **信号源状态列表**: 每项显示最新值和变化方向(↑/↓)

**修改文件**:
- `pc/src/App.tsx` - 增加 `/risk` 路由
- `pc/src/components/layout/Sidebar.tsx` - 增加导航入口

#### 2.1.3 风险自动通知
**修改**: `pc/electron/services/NotificationService.cjs`

规则:
- 风险等级从中以下升到中以上 → 推送"近期状态有变化，建议关注"
- 连续3天行为异常 → 推送"已经好几天没写日记了，要不要聊聊？"
- 风险等级达到高/危急 → 推送 + 自动弹出 CrisisInterventionModal

### 2.2 Phase 2: 打字行为分析（无感识别创新）

**目标**: 体现"无感识别"核心理念

#### 2.2.1 日记编辑器数据采集
**修改**: `pc/src/components/diary/DiaryEditor.tsx`

采集指标:
- **输入速度**: 字符/分钟
- **删除键比例**: 删除次数/总按键次数
- **停顿次数**: >2秒无输入的次数

实现:
```typescript
// 监听 keydown/keyup 事件
// 记录每次按键时间戳
// 保存时计算指标并调用 behavior:analyzeTyping IPC
```

#### 2.2.2 行为分析扩展
**修改**: `pc/electron/services/BehaviorAnalyzer.cjs`

新增 `analyzeTyping` 方法:
- 接收打字行为数据
- 与个人基线对比（需7天数据）
- 生成异常信号写入 behaviorRecords

### 2.3 Phase 3: 演示数据故事线（比赛演示必备）

**目标**: 比赛演示时有完整叙事

#### 2.3.1 故事线设计
**修改**: `pc/src/utils/seedDemoData.ts`

**虚拟用户**: 小明，大学生，使用FriendOS 2周

| 阶段 | 天数 | 心情 | 任务完成率 | 日记特征 | 系统响应 |
|------|------|------|-----------|----------|----------|
| 正常 | Day 1-5 | 4-5分 | 80%+ | 200-300字，积极 | 正常记录 |
| 压力 | Day 6-8 | 3分 | 50% | "好累""压力大" | 行为异常检测 |
| 焦虑 | Day 9-11 | 2分 | 20% | 50-100字，消极 | 风险评分升高 |
| 危机 | Day 12 | 1分 | 0% | "活着没意思" | 危机干预触发 |
| 干预 | Day 13-14 | 3-4分 | 60% | 使用呼吸/正念 | 风险评分下降 |

#### 2.3.2 配套数据生成
- `emotionRecords` - 情绪变化曲线
- `behaviorRecords` - 行为异常记录
- `assessments` - PHQ-9/GAD-7评分变化
- `healthProfiles` - 六维健康状态
- `conversationSummaries` - AI聊天记录
- `therapyRecords` - 治疗练习记录

## 六、竞赛亮点总结

### 6.1 技术创新
1. **三层情感分析架构**: 关键词→ONNX→Qwen3，兼顾速度和准确度
2. **无感识别**: 打字行为+日记情绪+行为模式，无需主动填量表
3. **统一风险评分**: 多信号源融合，0-100量化风险指数

### 6.2 心理学专业性
1. **标准量表**: PHQ-9、GAD-7、PSS-10
2. **科学模型**: PANAS情绪模型、C-SSRS风险评估、CBT认知行为疗法
3. **临床参考**: 4-7-8呼吸、共振频率呼吸、正念减压

### 6.3 产品完整度
1. **13个功能模块**: 仪表盘、任务、日记、习惯、记忆、情绪、治疗、AI助手、评估、报告、同步、设置、风险
2. **完整闭环**: 识别→预警→干预→追踪→效果评估
3. **隐私优先**: 本地存储+数据加密+知情同意

### 6.4 中国本土化
1. **学生适配**: 学期节奏、学业压力、校园欺凌检测
2. **中文优化**: 含蓄表达理解、网络用语、方言支持
3. **文化敏感**: 病耻感、面子、家庭因素考虑

### 6.5 演示叙事
1. **完整故事线**: 虚拟用户2周心理变化轨迹
2. **危机干预**: 从风险识别到干预到恢复的完整流程
3. **可视化呈现**: 风险仪表盘、情绪趋势、行为分析

## 八、默认假设与约束

1. **不引入新npm依赖**，所有动画用CSS+原生JS实现
2. **风险评分权重为初始值**，后续可根据实际数据调优
3. **打字行为采集仅在日记编辑器中进行**，不采集其他页面
4. **数据导出为JSON格式**，不做额外加密
5. **不改动现有数据库schema版本**，所有新字段使用已有表的扩展

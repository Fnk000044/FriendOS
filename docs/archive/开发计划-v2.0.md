## 二、待完成工作（仅按内容分组，无时间安排）

### Phase 1：安全与 Bug 修复

#### 1.1 IndexedDB 敏感数据加密
**文件**: `pc/src/db/`（新建 crypto.ts，修改 index.ts）
**背景**: 日记、记忆、危机日志、健康档案、情绪记录、评估结果以明文存在 IndexedDB 中。

**方案**:
- 新建 `crypto.ts`，使用 Web Crypto API AES-GCM 加密
- 主密钥从 app lock 密码通过 PBKDF2 派生
- 加密字段：`diaries.content/title`、`conversationSummaries`、`emotionRecords`、`assessments`
- 解密失败时回退读明文（兼容迁移期旧数据）
- 写操作自动加密存储

```
方案简述:
- 加密: plaintext → AES-GCM → { iv, ciphertext } → base64 → 存入 Dexie
- 解密: Dexie 读取 → base64 解码 → AES-GCM 解密 → plaintext
- 密钥: PBKDF2(password, salt='friendos-db-key', iterations=100000) → 256-bit key
- 未设密码时: 使用固定 salt 派生（提防随意读取，不防定向攻击）
```

#### 1.2 StatusBar archived 查询修复
**文件**: `pc/src/components/layout/StatusBar.tsx:36`
**Bug**: `db.habits.where('archived').equals(0)` 查询 bool 字段，应改为 `.equals(false)`
**影响**: 当前 JS 中 `0 == false` 为 true 所以没出问题，但语义错误且不符合 Dexie 类型安全。

#### 1.3 打通 saveConversationSummary 死代码
**文件**: `pc/src/services/ai/ConversationMemory.ts`、`pc/src/hooks/useAI.ts`
**背景**: `saveConversationSummary` 已完整实现（含 extractKeyTopics、detectEmotionalState），但从未被调用。
**方案**:
- 在 `useAI.ts` 的 `sendMessageStream` 结束后调用 `saveConversationSummary`
- 提取的关键主题写入 `db.memoryCandidates`（sourceType: 'chat'）

#### 1.4 AnimatedNumber 接入
**文件**: `pc/src/components/common/AnimatedNumber.tsx`
**背景**: 组件已实现（requestAnimationFrame + easeOutCubic），但无引用。

### Phase 2：体验增强

#### 2.1 危机警报音频通知
**文件**: `pc/src/components/crisis/CrisisInterventionModal.tsx`
**背景**: 仅视觉脉冲，用户屏幕关闭/应用最小化/视障时无法察觉。
**方案**:
- Web Audio API 生成短促警报音（OscillatorNode，无需音频文件）
- `riskLevel === 'high'` 播放一次
- `riskLevel === 'critical'` 循环播放直到用户交互
- `prefers-reduced-motion` 下降低音量

#### 2.2 自动备份提醒
**文件**: `pc/src/pages/SettingsPage.tsx`、`pc/electron/services/NotificationService.cjs`

- 备份文件命名 `friendos-backup-{YYYY-MM-DD}.json`

#### 2.3 聊天流式输出光标

### Phase 3：性能优化

#### 3.1 aiStore 内存 FIFO 限制
**文件**: `pc/src/stores/aiStore.ts`
**背景**: persist 层限制 50 条，但运行时无上限。
**方案**:
- `addMessage` 中当 messages 超过 200 条时移除最早的消息
- 保留最近对话摘要作为上下文

#### 3.2 QuickStats 查询合并
**文件**: `pc/src/components/dashboard/QuickStats.tsx`
**背景**: 5 个独立 `useLiveQuery`，可分组合并。
**方案**:
- 使用单个 `useLiveQuery` + `db.transaction('r', ...)` 内 `Promise.all`

#### 3.3 ThoughtRecord 定时器清理
**文件**: `pc/src/components/therapy/ThoughtRecord.tsx`
**背景**: setTimeout 未在组件卸载时清理。
**方案**:
- Timer 存入 `useRef`，cleanup 中 `clearTimeout`

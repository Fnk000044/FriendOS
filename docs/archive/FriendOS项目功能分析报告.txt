================================================================================
                    FriendOS（知己）项目功能分析报告
                 基于实际代码的全面分析（非开发计划）
================================================================================

项目定位：基于 Electron + React 的 AI 心理健康陪伴桌面应用，面向大学生群体
代码量：约 25,000+ 行，24/25 个服务文件为完整实现
技术栈：Electron 42 + React 18 + TypeScript 5.5 + Vite 5.4 + Tailwind CSS
        状态管理: Zustand | 数据库: Dexie (IndexedDB) | 图表: Recharts
        AI: node-llama-cpp (Qwen3 0.6B GGUF) + onnxruntime-node (BERT)

================================================================================
一、14 个页面模块（全部已实现）
================================================================================

1. DashboardPage (/)
   - 今日概览：任务完成率、日记状态、习惯打卡、情绪健康指数
   - AI 干预建议、每周回顾、每日语录
   - 使用 useAI、useDailyRecords、useLiveQuery

2. TasksPage (/tasks)
   - 任务 CRUD，4 分区（今日/待办/已完成/滚转）
   - 优先级（紧急/高/中/低）、分类标签、重复任务创建
   - 复合索引查询优化，任务滚转机制

3. DiaryPage (/diary)
   - 日历视图 + 日记列表，分页加载
   - 引导式日记模板（感恩/成就/情绪触发/晚安/自由）
   - 心情选择器（1-5 分）、8 维情绪选择器（3 级强度）
   - 实时情感分析（1.5 秒防抖）、打字行为追踪

4. EmotionPage (/emotion)
   - 情绪趋势图（7/14/30 天切换）
   - 健康雷达图（6 维：情绪/压力/精力/社交/睡眠/自理）
   - 情绪热力图（12 周 GitHub 风格）
   - AI 情绪预测（7 天）、健康画像自动生成

5. HabitsPage (/habits)
   - 习惯网格展示、打卡计数
   - 连续天数火焰图标（1 火焰 <7天, 2 火焰 <30天, 3 火焰 >=30天）
   - 日/周/月频率支持

6. MemoriesPage (/memories)
   - 记忆 CRUD、分类、标签、置顶
   - AI 候选记忆自动提取（从日记/任务/快捕中）
   - 规则扫描 + AI 增强提取两种模式
   - 候选记忆确认/拒绝工作流

7. AssistantPage (/assistant)
   - AI 聊天面板，流式输出（16ms 缓冲刷新）
   - 30+ 危机关键词实时检测
   - Markdown 渲染、自动滚动、中止请求支持
   - 5 种 AI 语气（专业/友好/简洁/鼓励/咨询师）

8. AssessmentPage (/assessment)
   - PHQ-9 抑郁筛查（9 题，0-3 分）
   - GAD-7 焦虑筛查（7 题，0-3 分）
   - PSS-10 压力评估（10 题，0-4 分，含反向计分）
   - 评估历史记录、PHQ-9 第 9 题自动触发危机干预

9. TherapyPage (/therapy)
   - CBT 思维记录（7 步临床协议，15 种认知扭曲识别）
   - 呼吸练习（4 种模式：4-7-8/方块/腹式/共振频率）
   - 正念冥想（3 种类型：身体扫描/觉察呼吸/慈悲冥想）
   - 安全筛查问卷（PTSD、精神病性症状、危机状态）
   - 练习前后情绪追踪

10. RiskDashboardPage (/risk)
    - 综合风险评分（0-100），5 级风险等级
    - 5 源雷达图（情绪/行为/量表/聊天/日记）
    - 风险趋势面积图（7/14/30 天）
    - 各信号源独立评分卡片与权重展示
    - 风险因子列表

11. ReportsPage (/reports)
    - 日/周/月报告生成
    - AI 生成分析（优先本地 LLM，规则兜底）
    - 任务完成率、情绪趋势、习惯完成率图表
    - 健康雷达图、每周报告卡片

12. SettingsPage (/settings)
    - 数据导入/导出（JSON，覆盖 18 张表）
    - 数据重置、Demo 数据生成
    - 语言切换（中/英文）
    - 主题切换（亮色/暗色/跟随系统）
    - 快捷键配置（冲突检测）
    - AI 模型状态、通知设置、应用锁设置
    - 存储路径查看

13. SyncPage (/sync)
    - LAN 同步服务器（HTTP，随机端口，UUID 令牌，10 分钟 TTL）
    - QR 码生成（手机扫描连接）
    - 同步历史记录

14. WelcomePage (首次启动)
    - 语言选择（中/英文）
    - 隐私知情同意（3 张信息卡 + 2 个复选框）

二、后端服务层（8 个 Electron 服务，42 个 IPC 通道）
================================================================================

1. RiskScoringEngine.cjs (411 行)
   - 5 源加权风险评分引擎
   - 信号源权重：情绪 30% + 行为异常 25% + 量表 25% + 聊天 10% + 日记 10%
   - 风险等级：0-25 低 / 26-50 中低 / 51-75 中 / 76-90 高 / 91-100 危急
   - IPC: risk:calculate, risk:getTrend

2. EmotionAnalysisEngine.cjs (780 行)
   - PANAS 情绪模型（10 正性 + 10 负性维度）
   - 6 维 Ekman 情绪（快乐/悲伤/愤怒/恐惧/惊讶/厌恶）
   - 社交活动评分（25 个社交关键词）
   - 睡眠模式分析（深夜写作检测）
   - 情感健康指数计算（加权：情感 25% + 心情 20% + 任务 15% + 习惯 15% + 社交 10% + 睡眠 15%）
   - 风险等级计算（6 因子）
   - 洞察和建议生成（中文）
   - IPC: emotion:analyzeDiary, emotion:analyzeConversation, emotion:calculateHealthIndex,
          emotion:calculateRiskLevel, emotion:generateInsights, emotion:generateSuggestions

3. SentimentService.cjs (456 行)
   - 3 层情感分析流水线：
     第 1 层：关键词预筛（23 个危机关键词 + 48 正面词 + 60 负面词）
     第 2 层：ONNX BERT 情感分类（负/中/正概率）
     第 3 层：Qwen3 语义判断（区分真实自杀意念 vs 隐喻/歌词/讽刺）
   - 危机关键词：想死、自杀、不想活、遗书、解脱等
   - Prompt 注入防御（<<<USER_TEXT_START>>> 分隔符 + 三引号转义）
   - IPC: sentiment-analyze, sentiment-cloud-analyze, sentiment-set-api-key,
          sentiment-get-model-status

4. BehaviorAnalyzer.cjs (531 行)
   - 个人基线建立（7 天+历史数据，均值/标准差）
   - 每日行为异常检测（低情绪/零任务/习惯中断/无日记/深夜活动/短日记）
   - 行为趋势分析（连续无日记/连续低情绪/任务完成率骤降/习惯中断/情绪波动/深夜比例）
   - 打字行为分析（速度/删除率/停顿率/会话时长）
   - 打字基线计算（3+ 次会话）
   - IPC: behavior:analyzeDaily, behavior:analyzeTrends, behavior:calculateBaseline,
          behavior:generateSummary

5. LocalModelService.cjs (165 行)
   - node-llama-cpp 封装，Qwen3 0.6B GGUF 推理
   - 4096 上下文大小
   - 非流式 / 流式（逐 token 回调）
   - 每次调用创建新 LlamaChatSession（避免对话交叉污染）
   - IPC: local-model-complete, local-model-complete-stream, local-model-dispose

6. NotificationService.cjs (363 行)
   - 定时提醒系统（60 秒轮询循环）
   - 日记/习惯/自定义提醒
   - 风险等级变化通知：
     中级以上 → "近期状态有变化，建议关注"
     连续 3 天异常 → "已经好几天没写日记了，要不要聊聊？"
     高/危急 → 紧急关怀通知
   - 输入验证（字符串长度、时间格式、日期范围）
   - IPC: notification:setReminders, notification:getReminders, notification:addReminder,
          notification:removeReminder, notification:toggleReminder, notification:startCheck,
          notification:stopCheck, notification:test

7. ModelRegistry.cjs (60 行)
   - 模型注册表：qwen3:0.6b (Qwen3-0.6B-Q4_K_M.gguf, 379 MB, Q4_K_M)
   - 支持 dev / asar 打包路径解析
   - IPC: local-model-list, local-model-init

8. ApiKeyStore.cjs (108 行)
   - Electron safeStorage 加密存储（Windows DPAPI / macOS Keychain / Linux libsecret）
   - 自动迁移旧明文格式
   - IPC: api-key-exists, api-key-get, api-key-set

三、AI 服务层（12 个文件）
================================================================================

1. AIService.ts (219 行)
   - 核心编排器：initialize() / sendMessage() / sendMessageStream()
   - Prompt 注入防御：50+ 行 sanitizeUserInput()，Unicode NFKC 规范化，
     零宽字符移除，17 种注入模式（中英文），5000 字符限制
   - 参考 OWASP LLM Security Guidelines
   - 提供者链：LocalModelProvider → ApiProvider → StubProvider

2. prompts.ts (122 行)
   - 5 种详细语气模板（每种 10-30 行系统提示）
   - 危机协议：所有语气必须包含，指定检测触发器、响应步骤、热线号码
   - 咨询师模式：完整 CBT 框架指导
   - 中国文化敏感性：面子文化、家庭压力、孝道、心理健康污名化、集体 vs 个人
   - buildSystemPrompt() 结构化段落

3. ContextService.ts (163 行)
   - 5 分钟 TTL 缓存，跨天失效
   - 并行数据库查询（7 个并发 Promise.all）
   - 处理：今日任务、近 7 天日记、习惯完成状态、近期记忆、对话摘要
   - 集成学期阶段检测 + 蓄意表达检测

4. ConversationMemory.ts (201 行)
   - 对话摘要保存（XSS 消毒，HTML 实体编码）
   - 关键消息提取（情绪关键词 → 事件关键词 → 最长消息）
   - 8 类主题提取（工作/学习/情绪/家庭/健康/社交/压力/心情）
   - 情绪状态检测（正/负/中性词计数）
   - 自动清理（保留最近 20 条）

5. ApiProvider.ts (191 行)
   - 4 家在线 API 支持：DeepSeek、OpenAI、Anthropic、自定义 OpenAI 兼容
   - 可用性检测：5 分钟缓存、5 秒超时 ping、30 秒失败冷却
   - SSE 流式解析：data: 前缀、[DONE] 处理、120 秒超时

6. LocalModelProvider.ts (149 行)
   - Electron IPC 桥接
   - 0.6B 小模型优化：简化系统提示、仅保留 2 轮对话
   - 温度 0.7/0.5，最大 token 512/200

7. StubProvider.ts (90 行)
   - 离线模板回复兜底
   - 关键词分类：问候/计划分析/状态/记忆/帮助/默认
   - 500-1500ms 模拟思考延迟

8. WeeklyReportService.ts (177 行)
   - 7 天数据聚合：日记、任务、习惯日志、评估、情绪记录
   - 统计：平均心情、任务完成率、心情趋势（前半 vs 后半，0.15 阈值）

9. ReportAIService.ts (254 行)
   - 双策略：AI 优先 + 规则兜底
   - AI 路径：发送结构化数据到 Qwen3，期望 JSON 响应
   - 规则路径：心情自适应摘要、日记频率洞察、风险检测

10. ProactiveService.ts (218 行)
    - 6 种触发类型：低情绪/无日记/低效率/习惯中断/高风险/深夜
    - 优先级级联：高风险情绪优先，连续低情绪 3 天，日记空白 3+ 天，
      任务完成率 <30%，习惯完成率 <30%，深夜活动 3+ 次
    - 每种触发 3 条随机关怀消息
    - 每天仅触发一次（localStorage 控制）

11. EmotionPredictionService.ts (125 行)
    - 7 天情绪预测：7 天移动平均 + 线性回归 + 周期性检测
    - 置信度衰减：max(0.3, 1 - i*0.1)
    - 趋势检测：0.3 阈值

12. ChineseLocalizationService.ts (281 行)
    - 蓄意表达检测：7 种文化感知模式（如"我没事"可能意味着"我不好"）
    - 网络俚语词典：27 条（如 yyds=正性 0.9, 摆烂=负性 0.75）
    - 方言识别：18 条，4 种方言（东北/四川/粤语/上海）
    - 综合中文情感：标准分 + 俚语调整(30%) + 蓄意表达调整(-0.2)

四、情绪与风险分析（6 个文件）
================================================================================

1. RiskAssessment.ts (349 行)
   - C-SSRS 框架（Columbia Suicide Severity Rating Scale，FDA/WHO 认可）
   - 将危机等级 0-4 映射到 C-SSRS 等级 0-6
   - 8 个风险因子加权评分：
     (1) 危机关键词 → C-SSRS 映射（权重 30-100）
     (2) 高/中风险情绪（权重 15-40）
     (3) 连续低情绪（权重 15-30）
     (4) 情绪波动 >1.5（权重 15）
     (5) 连续无日记（权重 8-15）
     (6) 任务完成率骤降（权重 10）
     (7) 习惯中断（权重 6-12）
     (8) 深夜活动比例 >0.6（权重 10）
   - 风险分类：critical/high/medium/medium_low/low

2. HealthProfileService.ts (227 行)
   - 6 维健康画像计算：
     情绪：情感分 + 心情评分均值
     压力：负性情绪最大值（恐惧/愤怒/悲伤）
     精力：快乐(60%) + 任务完成(25%) + 习惯率(15%)
     社交：来自情绪记录的社交评分
     睡眠：深夜活动惩罚 + 心情相关
     自理：习惯一致率
   - 情感健康指数（IPC + 公式兜底）
   - 情绪波动：心情评分标准差

3. StudentAdaptationService.ts (305 行)
   - 学期阶段检测：中国大学校历（假期/期中/期末/常规，5 阶段，压力 15-80）
   - 学业压力检测：30+ 关键词（考试/GPA/论文/退学等），压力 = min(100, 匹配数*20)
   - 霸凌检测：20+ 关键词（直接/间接/网络霸凌），严重程度分类
   - 热线号码：12355

4. InterventionRecommendationService.ts (151 行)
   - 基于健康维度的个性化建议：
     高压力(>70) → 4-7-8 呼吸
     低情绪(<40) 或高压力(>60) → 正念身体扫描
     低精力(<40) → 15 分钟散步
     低社交(<40) → 联系朋友
     低睡眠(<40) → 睡前放松仪式
     始终包含：CBT 思维记录

5. EmotionPredictionService.ts (125 行)
   - 7 天情绪预测：移动平均 + 线性回归 + 周期性检测
   - 置信度衰减、趋势方向检测

6. ChineseLocalizationService.ts (281 行)
   - 蓄意表达检测、网络俚语、方言识别、综合中文情感分析

五、数据层（18 张 IndexedDB 表，7 次 Schema 迁移）
================================================================================

v1: tasks, diaries, habits, habitLogs, memories, dailyRecords, quickCaptures, categories
v2: syncLogs
v3: memoryCandidates
v4: quotes
v5: emotionRecords, behaviorRecords, healthProfiles, crisisLogs,
    conversationSummaries, assessments, therapyRecords

核心数据模型：
- Task: 标题/描述/优先级/状态/分类/标签/日期/滚转/重复
- DiaryEntry: 日期/标题/内容/心情(1-5)/天气/标签
- Habit: 名称/颜色/图标/频率/目标/单位/提醒
- Memory: 标题/内容/类型/来源/标签/分类/置顶/归档
- EmotionRecord: 来源/情感分(-1~1)/6维情绪/风险等级/关键词
- BehaviorRecord: 日记/心情/任务/习惯/活跃时段/打字行为
- HealthProfile: 健康指数(0-100)/波动/风险等级/6维/洞察/建议
- Assessment: 类型(PHQ9/GAD7/PSS10)/分数/等级/建议
- TherapyRecord: 类型(思维记录/呼吸/正念)/前后情绪
- CrisisLog: 触发来源/触发内容/风险等级/处理状态
- ConversationSummary: 摘要/主题/情绪状态
- TypingBehavior: 平均速度/删除率/停顿率/会话时长

九、安全与隐私
================================================================================

1. 数据全本地存储：IndexedDB，无云上传
2. API 密钥加密：Electron safeStorage（Windows DPAPI）
3. 应用锁：PBKDF2（100,000 次迭代，SHA-256，256 位输出）
   - 三级向后兼容：PBKDF2 → SHA-256-salt → SHA-256
   - 成功解锁时自动升级旧格式
4. Prompt 注入防御：50+ 行消毒函数
   - Unicode NFKC 规范化
   - 零宽字符移除
   - 17 种注入模式检测（中英文）
   - 5000 字符长度限制
   - 参考 OWASP LLM Security Guidelines
5. 同步数据消毒：HTML 标签剥离、长度限制、白名单校验
6. 危机干预：30+ 危机关键词、5 秒强制倒计时、4 条心理热线
7. Electron 安全：CSP 头、导航阻止、窗口打开拒绝、权限请求拒绝、
   协议黑名单、UNC 路径阻止

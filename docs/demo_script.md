# FriendOS · 演示脚本（30 秒速览 + 5 分钟视频）

| 文档版本 | v2.0 |
|---|---|
| 撰写人 | 工程师 寇豆码 |
| 用途 | 决赛现场 30 秒速览路径 + 5 分钟答辩视频脚本 |
| 共用故事线 | 「小明 30 天」（正常 10d → 压力 8d → 焦虑 6d → 危机 2d → 恢复 4d，含 2 次预警事件） |

> 演示数据由 `seedDemoData.ts` 确定性注入（无随机数，两次运行完全一致）。所有页面/按钮/文案与打包版 UI 一一对应，可在断网 + 无 API Key 的决赛设备上逐字走通。

---

## 0. 演示前准备（打包版）

1. 启动 FriendOS 打包版（断网、无 API Key）。
2. 进入「设置 → 数据管理 → 一键注入 30 天演示数据」，确认弹窗后等待刷新。
3. 顶部横幅出现「演示模式 · 数据为模拟数据」即就绪。
4. （可选）打开「设置 → 自检」确认四态：联网=离线（灰）、模型=ONNX 就绪（绿）、Key=未配置（灰）、降级路径=离线模式-模板对话已就绪（黄）。

## 1. 30 秒速览路径（决赛现场版）

总时长约 30 秒，共 5 步，每步对应一个页面/操作。

| 步骤 | 时长 | 操作 | 页面 | 关键画面 | 演示要点 |
|---|---|---|---|---|---|
| 1. 倾诉 | 5s | 左侧导航 →「AI助理」；输入框输入：`最近考试压力好大` | ChatPage | 输入后消息上屏，气泡旁出现情感点（琥珀色 = negative） | 离线可用、秒回（无 30s 云等待） |
| 2. 情感识别 | 5s | 观察回复气泡下的来源徽标 | ChatPage | 徽标显示「本地」；回复引用上一轮主题 | 「本地」= 情感感知模板引擎（ONNX 4 分类驱动） |
| 3. 风险看板 | 10s | 左侧导航 →「风险评估」 | RiskDashboardPage | 综合风险总分 + 等级条 + 早期预警卡（黄/橙） | 多信号可解释风险评估（统计加权） |
| 4. 证据链下钻 | 5s | 点击评分卡或预警卡上的「查看证据链」 | EvidenceChainView（弹层） | 5 条信号贡献条（数值）+ 触发依据 + 建议动作 | 分数可解释，不是黑盒 |
| 5. 危机干预/热线 | 5s | 回到聊天页，输入：`活着没意思` | CrisisInterventionModal | 危机弹窗 + 热线卡（12356 / 400-161-9995）+「我不能替代专业医疗」 | 伦理红线：危机恒走固定回复 |

> 讲稿一句：**「FriendOS 是一个本地优先的心理健康伴侣：情感识别、风险预警、证据链全部在设备端完成，断网也能用，危机时刻有 24 小时热线兜底。」**

## 2. 5 分钟视频脚本建议（答辩视频）

共用「小明 30 天」故事线。建议总长 4:30 ~ 5:00，含片头/片尾字幕。

| 时间 | 场景 | 画面 | 旁白（建议） |
|---|---|---|---|
| 0:00-0:20 | 深夜低落 | 深夜台灯下，主角面对电脑/手机，输入「最近总睡不着，心里很乱」 | 「深夜两点，很多人像这样独自面对情绪。FriendOS 想要成为那个一直在线、又绝不外传的陪伴者。」 |
| 0:20-1:00 | 陪伴对话 | 聊天页逐条对话（≥3 轮）：倾诉 → 共情 → 引用主题 → 建议 | 「没有云、没有账号，情感识别在本地 ONNX 模型上运行。它记得你上一轮说的考试压力，在合适的时候给出陪伴与建议。」 |
| 1:00-1:40 | 情感识别 | 情绪分析页：趋势图、情感分布、健康画像 | 「每天写下的日记、聊过的话、任务的完成度，会被多信号地观察——情绪、行为、量表、聊天、日记五个维度。」 |
| 1:40-2:30 | 早期预警 | 风险看板：总分 72/100、等级「高」、预警卡「距临界点 3 天」 | 「当多个信号同时走弱，FriendOS 会给出统计早期预警。这不是玄学——每一项都有一条可下钻的证据链。」 |
| 2:30-3:10 | 证据链 | 点击「查看证据链」：5 条贡献条（数值）+ 触发依据 + 建议动作 | 「总分怎么来的？情绪 30%、行为 25%、量表 25%、聊天 10%、日记 10%，全部可解释；方法说明与模型卡公开可查。」 |
| 3:10-3:50 | 建议动作 | 证据链里点「做一次呼吸练习」→ 跳转治疗练习页 | 「证据链不只是展示，还会给出可执行的下一步：写日记、呼吸练习、量表评估，或者——在危机时刻，拨打热线。」 |
| 3:50-4:30 | 危机干预 | 输入危机文本 → 危机弹窗（12356 / 400-161-9995）→ 固定回复 | 「危机识别是 FriendOS 的底线能力。一旦检测到，立即弹出 24 小时热线与专业医疗提示——我们永远不做医疗替代，只做陪伴与转介。」 |
| 4:30-5:00 | 隐私承诺 | 隐私面板：数据只在本机 / AES-GCM 加密 / 无网络外联 / API Key DPAPI 加密 | 「所有数据只存在你的设备上，字段级加密，密钥不出设备。你的情绪，只有你自己知道。」 |

## 3. 素材清单（录屏/文案/热线卡）

- **录屏页面**：ChatPage（≥6 轮对话，含 1 次危机触发）、EmotionPage（趋势 + 预测卡）、RiskDashboardPage（评分卡 + 预警卡 + 证据链）、TherapyPage（呼吸练习）、SettingsPage（数据管理注入/清理 + 自检 + 隐私面板）、AppLayout（演示模式横幅）。
- **必录文案**：来源徽标「本地/云端」；预测卡 method 徽标（如 `logistic-regression`）+ note +「统计预测 ≠ 医疗诊断」；危机弹窗热线卡；演示模式横幅「演示模式 · 数据为模拟数据」。
- **热线卡（三处统一）**：全国心理援助热线 400-161-9995（24h）；全国统一心理援助热线 12356（24h）；北京心理危机研究与干预中心 010-82951332（24h）；统一话术含「我不能替代专业医疗」。
- **数据故事**：注入演示数据后，风险看板出现「小明」故事：offset -7 预警事件（PHQ-9 中重度 / GAD-7 中度 → high）、offset -4 危机日记（C-SSRS 意念 → critical）。

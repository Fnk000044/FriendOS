# 目录整理规范（FriendOS 仓库）

> 版本：v1.0 ｜ 维护：开发团队 ｜ 最后更新：2026-08
> 边界依据：根目录 `AGENTS.md`（三个源根约束），本规范只整理与说明，**不改变**源根边界。

## 1. 三个源根边界（引用 AGENTS.md，禁止破坏）

```
FriendOS/
├── pc/src/          # 渲染层 TypeScript（React + Zustand + Dexie）——源根 1
├── pc/electron/     # 主进程 CommonJS（沙箱 + contextBridge）——源根 2
├── pc/scripts/      # 构建/打包/评估脚本（Node）——源根 3
├── docs/            # 人类可读文档
├── 数据集1/ 数据集2/ 数据集3/   # 研究资产，只读，不改
├── 索引/  论文/                # 研究资产，只读，不改
└── version          # 单行版本号
```

**规则**：
- 代码改动只允许落在 `pc/src`、`pc/electron`、`pc/scripts`、`docs/`。
- `数据集1/2/3`、`索引/`、`论文/` 为只读研究资产，**禁止修改**（脚本可只读引用，如 `eval-sentiment.cjs` 读数据集3）。
- `pc/scripts/train_sentiment/` 是独立训练脚本，**不在本次迭代改动范围**（如需修改另立任务）。

## 4. 提交约定

- 提交前必跑：`cd pc && npm run test && npm run typecheck`。
- 不 commit：`pc/release/`、`pc/dist/`、`pc/node_modules/`、`node_modules/`。
- docs 改动与代码改动可在同一 PR，但提交信息需区分 `docs:` / `feat:` / `refactor:`。

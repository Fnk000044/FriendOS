## 一、项目总览

### 1.1 核心理念

**无感识别**：AI 通过用户的自然行为（写日记、聊天、完成任务、习惯打卡等）无感知地分析心理状况，而非要求用户主动填写量表。

### 1.2 技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                      Electron 桌面应用                        │
├─────────────────────────────────────────────────────────────┤
│  渲染进程 (React + TypeScript)                                │
│  ├── 13 个页面路由                                            │
│  ├── 8 个 Zustand Stores                                     │
│  ├── 15 个 Custom Hooks                                      │
│  └── 50+ UI 组件                                             │
├─────────────────────────────────────────────────────────────┤
│  主进程 (Node.js)                                             │
│  ├── SentimentService (三层情感分析)                           │
│  ├── EmotionAnalysisEngine (PANAS 模型)                      │
│  ├── BehaviorAnalyzer (行为分析)                              │
│  ├── LocalModelService (Qwen3 推理)                          │
│  ├── NotificationService (提醒)                              │
│  └── SyncServer (局域网同步)                                  │
├─────────────────────────────────────────────────────────────┤
│  数据层                                                       │
│  ├── Dexie (IndexedDB) — 18 张表                             │
│  ├── Qwen3-0.6B GGUF — 本地 LLM                             │
│  └── BERT ONNX — 情感分类                                    │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 三层情感分析架构

```
用户输入 → 关键词预筛 → ONNX 情感分类 → Qwen3 语义判定 → 最终结果
              ↓              ↓              ↓
           即时 (<1ms)    ~50ms         1-3秒
```

### 5.2 竞争优势

**FriendOS 独特优势：**

1. **桌面原生应用** — 市场上几乎无竞品是桌面原生
2. **功能最全面** — 唯一同时具备 AI 对话 + 日记 + 情绪追踪 + CBT + 呼吸 + 习惯的应用
3. **完全离线** — 本地 Qwen3 模型，无需联网，数据不出设备
4. **免费开源** — 无订阅费，无广告
5. **数据自主** — 用户完全控制自己的数据
6. **无感识别** — 通过自然行为分析心理状态，无需主动问卷

**FriendOS 劣势：**

1. **无移动端** — 大多数竞品是移动优先
2. **无专业治疗师** — BetterHelp/Talkspace 提供真人治疗
3. **AI 质量** — 0.6B 模型能力有限，不如云端大模型
4. **临床验证** — Woebot 有斯坦福临床验证，FriendOS 无
5. **用户规模** — 竞品有数百万用户，FriendOS 是新项目

### 5.3 差异化定位

```
FriendOS = 离线版 Woebot + 本地版 Daylio + 免费版 Moodfit
```

**目标用户：**
- 注重隐私、不愿将心理数据上传云端的用户
- 需要桌面端长时间使用的用户（学生、办公族）
- 预算有限、不愿支付订阅费的用户

## 七、UI/UX 优化

### 7.1 柔和玻璃拟态（Soft Glassmorphism）设计方案

**当前风格：** Tailwind 默认实色背景 `#F8FAFC` + 纯白卡片 `#FFFFFF` + 阴影  
**目标风格：** 柔和渐变背景 + 半透明毛玻璃卡片 + 装饰光斑  
**设计原则：** 温暖安全感 > 炫酷科技感，心理健康应用需要低视觉压力

#### 7.1.1 设计效果预估

| 方面 | 当前 | 改造后 | 评估 |
|------|------|--------|------|
| 视觉层次 | 平面实色 | 渐变底 + 毛玻璃卡片 | 显著提升 |
| 温暖感 | 冷白 | 淡蓝→淡青→淡橙渐变 | 大幅提升 |
| 现代感 | 2020 风格 | 2024-2026 趋势 | 大幅提升 |
| 可读性 | 良好 | 透明度 72% 保证可读 | 保持 |
| 性能 | 基线 | `backdrop-filter: blur(12px)` | Electron 无压力 |
| 深色模式 | 实色深灰 | 半透明深蓝 | 天然适配 |

## 九、答辩要点

### 1. 核心卖点：无感识别

"我们的系统不需要用户主动做心理测试，而是通过用户日常写日记、聊天、完成任务等自然行为，无感知地分析心理状况。这是与市面上所有产品最大的区别。"

### 2. 技术创新

- **无感识别**：通过自然行为分析心理状态，无需主动问卷
- **三层情感分析**：关键词（实时）→ BERT ONNX（本地）→ Qwen3（语义判定）
- **本地 AI 推理**：Qwen3 + BERT ONNX，数据不出设备
- **主动关怀**：AI 基于分析结果主动发起关心，而非被动等待

### 3. 痛点

- 大学生心理问题高发（20-30% 检出率）
- 传统咨询三大障碍：stigma、成本高、预约难
- 现有产品需要主动做问卷，用户参与度低
- 现有产品数据上传云端，隐私风险大

### 4. 评委可能的问题

| 问题 | 回答要点 |
|------|----------|
| 无感识别准确吗？ | 三层架构交叉验证 + 行为模式多维度分析，比单次问卷更全面 |
| 和 ChatGPT 有什么区别？ | 无感识别 + 本地隐私 + 主动关怀 |
| 数据安全怎么保证？ | 全部本地存储，不上传云端，可选加密 |
| 能替代专业心理咨询吗？ | 不能，定位是辅助工具，危机时引导寻求专业帮助 |
| 有什么创新点？ | 无感识别 + 三层情感分析 + 本地AI推理 + 主动关怀 |
| 和市面上产品对比？ | 功能最全面、唯一桌面原生、完全离线、免费开源 |

### 5. 竞品对比要点

```
FriendOS = 离线版 Woebot + 本地版 Daylio + 免费版 Moodfit
```

- 唯一同时具备 AI 对话 + 日记 + 情绪追踪 + CBT + 呼吸 + 习惯的应用
- 唯一桌面原生心理健康应用
- 唯一完全离线的 AI 心理助手
- 唯一免费开源的心理健康工具
